\# CloudSentinel



\## Self-Healing DevSecOps Platform on AWS



CloudSentinel is a cloud-native DevSecOps platform designed to automate application delivery, infrastructure provisioning, monitoring, incident detection, and automated recovery.



\## Objectives



\- Infrastructure as Code using Terraform

\- Containerization using Docker

\- CI/CD using GitHub Actions

\- Secure AWS deployment

\- Application monitoring

\- Automated incident detection

\- Self-healing infrastructure

\- Deployment rollback

\- Security scanning



\## Architecture



GitHub → GitHub Actions → Docker → Amazon ECR → AWS → CloudWatch → EventBridge → Lambda → Auto Recovery



\## Technology Stack



\- AWS

\- Terraform

\- Docker

\- GitHub Actions

\- Python FastAPI

\- CloudWatch

\- Lambda

\- EventBridge

\- IAM

\- Amazon ECR
